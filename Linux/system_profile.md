## Binary Number Representation

### 1. Decimal 75 to Binary

Repeated division by 2:

75 / 2 = 37 remainder 1
37 / 2 = 18 remainder 1
18 / 2 = 9 remainder 0
9 / 2 = 4 remainder 1
4 / 2 = 2 remainder 0
2 / 2 = 1 remainder 0
1 / 2 = 0 remainder 1

Reading the remainders from bottom to top:

75 (decimal) = 1001011 (binary)

### 2. Binary 110101 to Decimal

Using positional weights:

110101 =

(1 x 2^5) +
(1 x 2^4) +
(0 x 2^3) +
(1 x 2^2) +
(0 x 2^1) +
(1 x 2^0)

= 32 + 16 + 0 + 4 + 0 + 1

= 53 (decimal)

### 3. Why Computers Use Binary

Computers use binary internally because digital electronic circuits can reliably represent two states, ON (1) and OFF (0), making data storage and processing simpler and more reliable.
